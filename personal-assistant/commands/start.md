description: Morning standup — review tasks, memory, and calendar, then plan the day
---

Run a quick morning standup. Be concise and conversational, like a colleague checking in — not a report.

1. **Task Board**: Read `Task Board.md` (vault root). Summarize what's on the plate — group by status/priority if the file supports it. If the file doesn't exist yet, say so and skip to step 2.
2. **Memory**: Read `.claude/memory.md`. Surface any open follow-ups, context, or reminders left over from previous sessions. If empty, skip silently.
3. **Time-sensitive items**: Scan the Task Board (and calendar file/notes if one is referenced in it) for anything due today or overdue. Call these out first if they exist.
4. **Prioritize**: Propose a short, ordered plan for today based on 1–3, weighing deadlines and stated priority. Keep it to a handful of items, not the whole backlog.
5. **Cleanup check**: Ask if anything finished yesterday should be checked off or removed from the Task Board. Apply the edit once confirmed.

Keep the whole exchange tight — this should read like a 2-minute standup, not a full status report.
